# saibro.app.br

Página "em breve" do Saibro. Estático, sem build: `index.html` + `assets/`.

- Hospedagem: GitHub Pages (branch `main`, raiz). `CNAME` aponta pra `saibro.app.br`.
- DNS (Registro.br): 4 registros `A` pros IPs do GitHub Pages + `CNAME www`.
- Trocar o logo: substituir `assets/logo.svg` (ou ajustar o `src` em `index.html`).
